# Skill: interview prep

Built only from `career-context.md` and the job's `notes.md`.

## The set
1. "Tell me about yourself" (60–90s, tuned to the track).
2. A 2-minute walkthrough of one system built (pick the story that best fits the posting).
3. The hardest likely question for this background (e.g. architecture degree → tech, the gap since
   Oct 2025, PM vs CSM direction).
4. "Why this kind of role / why this company."
5. One strong story in STAR form.
6. Clean answers for anything that must not be revealed (see §3 Never claim).

Each with 2–3 tough follow-ups. Run it as a mock: ask one question, wait for Kfir's answer, give
blunt feedback, move on.

Save the prep in the job's `notes.md` → Interview prep. Answers Kfir likes go back into
`career-context.md` §7 Ready answers.
