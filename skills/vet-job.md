# Skill: vet a posting

Always first. Most postings should die here, before any CV work.

## Steps
1. Check `jobs/tracker.md` — already vetted? Say so and stop.
2. Open the posting live. Closed / reposted / aggregator-only → say so.
3. Fill the facts (Unknown beats a guess): role, pay range, location/remote, reports to, what the
   company does, stage/funding, approx employees.
4. **Title vs real duties:** read the responsibilities, not the title. Flag anything that is really
   a sales/quota, support-only, or project-coordination job (check `career-context.md` §5 Not interested).
5. Check hard filters in `career-context.md`: location/remote, work authorization, pay floor, seniority.
6. Give a **one-line verdict**: **Apply / Stretch / Skip** + the reason.
7. Pick the track (PM / CSM) and pull **8–12 key terms** a recruiter or ATS would match on.
8. Add a row to `jobs/tracker.md` (status *Sweep lead* or *Interested*; *Passed* for skips).
9. If Apply/Stretch: create `jobs/YYYY-MM-DD Company/notes.md` from `jobs/_template/notes.md`.

## Output format
```
<Company> — <Role>  |  <Apply / Stretch / Skip>
Why: <one line>
Pay: <range or Unknown> | Remote: <…> | Stage: <…> | Size: <…>
Real duties: <one line>   Track: PM / CSM
Key terms: a, b, c, …
```
